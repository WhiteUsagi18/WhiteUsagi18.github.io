## Summary Exploitation
The Cap machine on Hack The Box was an easy-level challenge that required careful enumeration and exploitation of a misconfigured web service. After identifying open ports through Nmap, I discovered a website that allowed downloading packet capture (PCAP) files, which turned out to be vulnerable to an Insecure Direct Object Reference (IDOR). By abusing this vulnerability, I could access unintended captures and extract sensitive credentials that granted me initial access to the system. From there, further enumeration revealed a misconfigured capability that I was able to exploit to escalate privileges and gain root access. By chaining enumeration, the IDOR vulnerability, credential extraction, and capability abuse, I was able to fully compromise the machine.

## Privilege Escalation
### Root Flag
Things that I always start to privesc to the root is by running the linpeas to scan what are the misconfig, vulnerabilities and permissions that we have.

Run:
`./linpeas.sh`

![Pasted image 20250825205334.png](/assets/img/cap/Pasted image 20250825205334.png)
Here is the critical part, we have a permission to use the python3.8. We can abuse this capability to privesc to root (Important things to remember that uid root is 0).

![Pasted image 20250825205248.png](/assets/img/cap/Pasted image 20250825205248.png)

Based on [this](https://www.hackingarticles.in/linux-privilege-escalation-using-capabilities/) article, we can use these commands:
```
/usr/bin/python3.8 -c 'import os; os.setuid(0); os.system("/bin/bash")'

id
```

![Pasted image 20250825210519.png](/assets/img/cap/Pasted image 20250825210519.png)
Boom! We successful change the uid to root. Now we have an access to the root.txt
